# Models Reference (inference.sh)

## Text-to-Video
- Veo 3.1 Fast `google/veo-3-1-fast` — fast with optional audio
- Veo 3.1 `google/veo-3-1` — best quality
- HappyHorse T2V `alibaba/happyhorse-1-0-t2v` — 1080P up to 15s
- Seedance 2.0 `bytedance/seedance-2-0` — sync audio, 1080p

## Image-to-Video
- Wan 2.5 `falai/wan-2-5` — animate any image
- Seedance 2.0 image `bytedance/seedance-2-0` — with `image` + `generate_audio`
- HappyHorse R2V `alibaba/happyhorse-1-0-r2v` — character-preserving

## Avatar
- OmniHuman 1.5 `bytedance/omnihuman-1-5`
- Fabric 1.0 `falai/fabric-1-0`

## Edit / Utils
- HappyHorse Edit `alibaba/happyhorse-1-0-video-edit`
- Topaz Upscaler `falai/topaz-video-upscaler`
- Foley `infsh/hunyuanvideo-foley`
