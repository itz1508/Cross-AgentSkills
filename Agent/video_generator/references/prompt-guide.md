# Video Prompt Guide

- Be specific: subject + action + environment + camera + style
- Example: "drone shot flying over a misty forest at dawn, cinematic, 4k"
- For Seedance `generate_audio: true` to include synced audio
- Image-to-video: provide `image_url` + motion prompt ("gentle camera movement, leaves rustling")
- Avatar: portrait `image_url` + `audio_url` (mp3) — frontal face works best
- Edit: "change background to snowy mountain" — describe target, not steps

See SKILL.md Tools table for model limits.
